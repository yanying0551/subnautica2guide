# Roadmap source brief

## Scope

This brief records the public development-status claims used by the roadmap page. It is not a prediction of release timing and does not publish a guaranteed, dated feature-by-feature roadmap.

## Editorial limits

The page only repeats claims that can be attributed to the sources above. It does not convert community speculation into confirmed features and does not publish a guaranteed dated feature-by-feature roadmap. The publicly discussed **2 to 3 years** development horizon is an attributed estimate, not a guaranteed release schedule. Future updates may make these claims stale, so the page must be rechecked after official announcements.
